About DejaVu Shield

DejaVu Shield is a comprehensive cybersecurity desktop application designed for security professionals and researchers. It provides real-time threat analysis, URL reputation checking, and advanced threat scanning capabilities.

Built with Python and featuring a modern Tkinter GUI, DejaVu Shield integrates with VirusTotal for industry-leading threat intelligence.

Key Features

🔍 URL Analysis

Check URLs against multiple threat databases for comprehensive safety analysis.

🦠 Threat Scanning

Real-time threat detection and analysis with detailed threat reports.

📊 Logging System

Complete audit trails for all operations and security events.

🪟 Windows Executable

Deploy as standalone .exe without Python installation required.

🎨 Modern UI

Professional dark-themed interface with intuitive controls.

⚡ Fast & Efficient

Optimized performance for rapid threat analysis and scanning.

Quick Start

System Requirements

  • Python 3.7 or higher
  • Windows 7 or later (for executable)
  • VirusTotal API key (free)

Installation Steps


# Clone repository
git clone https://github.com/e-akunor-security/DejaVu-Shield.git
cd DejaVu-Shield

# Create virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Configure API key
# Create .env file with your VirusTotal API key

# Run application
python main.py
