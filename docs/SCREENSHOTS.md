## How to Add Screenshots

1. **Run the application**:
   ```bash
   python main.py
   ```

2. **Take screenshots** of:
   - Main application window
   - Analysis results (both safe and malicious URLs)
   - Threat scanning interface
   - Export/report features

3. **Save to `docs/screenshots/`** directory:
   ```
   docs/screenshots/
   ├── main-window.png
   ├── analysis-results.png
   ├── threat-scanning.png
   └── export-feature.png
   ```

4. **Update this file** with actual screenshot descriptions

## Quick Start Visual Guide

1. **Launch Application**
   ```
   python main.py
   ```

2. **Enter URL**
   - Type URL in input field
   - Example: `https://example.com`

3. **Click Analyze**
   - Wait for threat analysis
   - View results in detail pane

4. **Review Report**
   - Check threat status
   - View detection details
   - Export if needed
